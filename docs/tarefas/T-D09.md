# T-D09 — Imagem de coleta de redes para o servidor
- **Papel:** dados · **Branch:** `feat/dados-imagem-coleta-redes` · ADR 0008
- **Contexto:** `docs/registro/consultas/2026-10-14-oracle-redes-diario*.md` (pergunta e proposta do Oracle, aprovada
  pelo Felipe em 14/10). A coleta diária sai do Mac (launchd) e vai para o servidor (systemd timer 06:00 UTC =
  03:00 BRT, `Persistent=true`). Infra do servidor é do agente Oracle; aqui é só o lado do repositório.

**Fazer:**
1. `packages/etl/Dockerfile` (ou `infra/etl.Dockerfile`): imagem arm64 mínima com `uv` + `packages/etl` +
   `packages/contratos` + `config/`, usuário não-root, entrada que roda o equivalente do `scripts/redes-diario.sh`
   (TSE → coleta; código 3 = limite de chamadas, retoma de hora em hora até 10 tentativas — manter o mesmo
   comportamento, nunca contornar limite ou bloqueio da Meta).
2. Caminhos por variável de ambiente (sem caminho do Mac embutido): entrada `redes_candidatos` lida de
   `/datasets` (ro); a série escrita em `/saida`. **Escrita atômica:** grava em `/saida/.novo/` e só com sucesso
   promove por `rename()`; falha no meio deixa a série anterior intacta. A série (`redes_perfis.parquet`) só
   acumula: a coleta **lê a série existente em `/saida`** e acrescenta o snapshot do dia — nunca recria do zero.
3. Falha explícita e legível: token vencido/inválido, app bloqueado (código 200), e **aviso** (saída ≠ 0 com
   mensagem clara) a partir de 14 dias antes de vencer o token (`debug_token` → `expires_at`).
4. Gravar `/saida/status.json`: `{inicio, fim, resultado: ok|limite|erro, motivo, perfis_coletados, coletado_em}`
   (ISO-8601 UTC) — a API (T-B19) expõe isso.
5. Workflow do Actions que builda e publica `ghcr.io/felipemaion/eleicoes2026-etl:latest` (arm64) a cada merge que
   toque `packages/etl`, `packages/contratos` ou `config/`. Avisar no handoff que o pacote GHCR nasce **privado** e o
   orquestrador precisa torná-lo público.
6. Documentar no handoff a **lista exata de variáveis** de ambiente lidas (META_TOKEN, META_APP_ID,
   META_APP_SECRET, caminhos, outras) — o Oracle precisa dela.
7. `docs/deploy.md`/`docs/fontes-de-dados.md`: a série mora em `data/redes/` no servidor (insubstituível → `data/`,
   que entra no backup; reconstruível → `datasets/`). `scripts/publicar-dados.sh` passa a excluir `redes/`
   (segunda camada de proteção).

**Aceite:** testes da promoção atômica (falha no meio preserva a série; sucesso acrescenta snapshot sem perder
os anteriores), do status.json e do aviso de expiração (sem rede, com fixture); `docker build` local arm64 ok e
`docker run` com `--help`/dry-run; `make lint test`; handoff `dados-T-D09.md` com variáveis e comando de execução;
`pronto T-D09`.
