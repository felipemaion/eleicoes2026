# T-W03 — Componentes D3 (barras, ranking, scatter, small multiples)
- **Papel:** frontend · **Fase:** F1 · **Issue:** #13 · **Branch:** `feat/frontend-graficos`
- **Depende de:** T-W01 (usa `escalas` de T-W02 se já existir; senão crie e T-W02 reutiliza)

## Objetivo
Biblioteca de gráficos D3 v7 acessíveis para as telas: KPIs, barras horizontais/ranking,
dispersão custo × votos (log), barras empilhadas de receita por fonte, comparação 2022×2026
(slope/dumbbell) e small multiples.

## Escopo
`src/componentes/graficos/{kpi,barras,ranking,dispersao,empilhado,comparacao}.ts`, cada um
`render(container, dados, opcoes)` + `atualizar(dados)`; tabela alternativa acessível
(`<details>` com `<table>`) para cada gráfico; formatação pt-BR (`d3.formatLocale` com R$, milhar `.`).

## Critérios de aceite
1. Vitest com jsdom: renderiza o nº certo de marcas, eixos e rótulos; formatação pt-BR (R$ 1.234,56).
2. Dispersão em escala log trata zero (custo ou votos = 0) sem quebrar e sinaliza o ponto.
3. Acessível: `role="img"` + `aria-label` descritivo, foco por teclado nas marcas, tabela alternativa.
4. Cores só das paletas centrais.
5. `pnpm lint typecheck test build` verdes.
