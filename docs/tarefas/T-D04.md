# T-D04 — Municípios: malhas IBGE, AMC, área e PMTiles
- **Papel:** dados · **Fase:** F2 · **Issue:** #7 · **Branch:** `feat/dados-municipios`

## Objetivo
Geometria e tabelas de município para mapas e para a evolução 2022→2026.

## Escopo
1. `municipios` (Parquet): `cd_mun_ibge`, `cd_mun_tse`, `sg_uf`, `nm_municipio`, `area_km2` (IBGE),
   `cd_amc` (Área Mínima Comparável 2022↔2026; município novo agregado ao de origem — ex.: Boa
   Esperança do Norte/MT; documente a fonte oficial usada). Esta é a tabela `municipios_extra` que o
   backend espera (alinhe o nome com ele via handoff; o backend lê de `<dir>/municipios.parquet`).
2. Malhas IBGE (API v3, municípios por UF, qualidade adequada a zoom de município) → GeoJSON com
   propriedade `cd_mun_ibge` (int) e `nm` → **PMTiles** via tippecanoe (zooms 3–10, simplificação),
   nome com hash do conteúdo (`municipios.<hash>.pmtiles`) + `tiles/manifesto.json` com o nome atual.
   Também a camada de UFs. Verifique tamanho final (meta < 60 MB).
3. Zonas eleitorais (ADR 0003): Voronoi dos `locais_votacao` por ano recortado pelo município
   (município de zona única = o próprio polígono) → camada `zonas_<ano>` no PMTiles (propriedades
   `cd_mun_ibge`, `nr_zona`, `id` = `<cd_mun_ibge>-<nr_zona>`).
4. tippecanoe: se não instalado, `brew install tippecanoe` (local). Saída em `data/processed/tiles/`.

## Critérios de aceite
Testes de unidade (crosswalk, AMC, Voronoi em fixture pequena); todos os 5.570 municípios com
geometria e AMC; PMTiles abre e tem as camadas (verificar com `pmtiles show`); handoff com tamanhos.
Handoff `docs/registro/handoffs/dados-T-D04.md`; responder `pronto T-D04`.
