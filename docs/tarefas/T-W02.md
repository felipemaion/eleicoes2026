# T-W02 — Componente de mapa (MapLibre + D3) sobre fixture
- **Papel:** frontend · **Fase:** F1 · **Issue:** #12 · **Branch:** `feat/frontend-mapa`
- **Depende de:** T-W01

## Objetivo
Componente `mapa` reutilizável para todas as telas: polígonos municipais (e depois zonas/H3)
coloridos por indicador via `feature-state`, camada de densidade por pontos de local de votação,
legenda D3 e tooltip — tudo contra fixtures enquanto a API real não existe.

## Contexto
`docs/arquitetura.md` § Mapas, `docs/metodologia/cuidados.md` § Visualização, ADR 0003.
Geometria virá como PMTiles (T-D04) com propriedade `cd_mun_ibge`; para a fixture use um GeoJSON
pequeno (ex.: municípios de uma UF pequena, baixado da API de malhas do IBGE e simplificado,
guardado em `apps/web/tests/fixtures/`). Valores chegam como `{cd_mun_ibge: valor}`.

## Escopo
- `src/componentes/mapa/`: `criarMapa(container, opcoes)` → API `{definirValores(mapa, escala),
  definirNivel('municipio'|'zona'|'h3'), definirPontos(geojson), destruir()}`.
- Fonte vetorial abstrata: aceita `pmtiles://...` ou GeoJSON (fixture) — mesma interface.
- Escala e legenda: módulo `src/componentes/escalas/` (D3 `scaleQuantile`, `scaleThreshold`,
  `scaleDiverging`, `scaleLog`) que gera tanto a expressão de cor do MapLibre quanto a legenda SVG;
  **uma fonte de verdade de cor** (paletas do T-W01).
- Densidade: camada `heatmap` + `circle` (raio ∝ √votos) para pontos de locais de votação.
- Tooltip acessível (também acionável por teclado) com valor absoluto, taxa e eleitorado.
- Estilo base leve sem API key (ex.: demotiles.maplibre.org ou estilo vazio com fundo neutro).

## Critérios de aceite
1. `escalas` (Vitest): quantis/limiares corretos; mesmas quebras aplicáveis a dois conjuntos (2022/2026);
   divergente centrada em 0 (swing) e em 1 com log (LQ).
2. Expressão `match`/`step` do MapLibre gerada a partir da escala (teste de unidade).
3. Legenda sempre com unidade e denominador; sem coroplético de valores absolutos (o componente
   recusa `tipo: 'absoluto'` em modo coroplético e sugere símbolos proporcionais).
4. Playwright: mapa carrega a fixture, muda valores sem recarregar geometria, tooltip aparece.
5. `pnpm lint typecheck test build` verdes.
