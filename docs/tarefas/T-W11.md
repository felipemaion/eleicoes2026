# T-W11 — Filtros e busca intuitivos; mapa focado no candidato
- **Papel:** frontend · **Branch:** `feat/frontend-filtros-busca` · **Depende de:** T-W10, T-B07 (busca/abrangência)
Peça do Felipe: "filtros mais fáceis de usar… buscar e os filtros precisam ser aprimorados, intuitivos e
iterativos. Ao escolher um candidato quero que mostre apenas a região que os votos dele foram feitos
(Presidente — país todo; Senador e deputados — o Estado). Os dados no mapa para presidente não estão
sendo carregados. Aparece 'Não foi possível carregar os dados agora' (pelo menos para Renan Santos)."
1. **Busca global** (combobox acessível, atalho `/`): digita nome/número/partido → sugestões instantâneas
   (`/api/busca`, debounce, setas/Enter, destaque do trecho), mostrando ano, cargo, UF, partido, votos;
   escolher leva à ficha ou fixa o candidato no mapa.
2. **Filtros**: chips/segmentos para ano e cargo, seletor de UF com busca (e "Brasil"), grupo com descrição
   curta; filtros dependentes (cargo restringe UFs com candidatos; presidente → Brasil), estado sempre no
   hash (deep-link), botão "limpar", contagem de resultados ao vivo; nada de recarregar a página.
3. **Mapa por candidato**: ao escolher candidato, enquadrar e mostrar só a abrangência (`abrangencia` da
   API: país para presidente; UF para senador/governador/deputados), esmaecendo o resto; idem para o mapa
   da ficha do candidato.
4. **Presidente**: mapa nacional carregando (após T-B07); exterior informado à parte ("votos no exterior:
   N, fora do mapa").
5. **Erros**: nenhuma tela mostra erro genérico para casos válidos — testar com Renan Santos (presidente,
   `sq 280002540694`), Kim Kataguiri, um senador e um deputado estadual; e2e para cada.
6. **Correções vistas na captura da T-W10**: (a) bloco de avisos longo empurra os KPIs — compactar em faixa
   recolhível ("Notas sobre os dados (5)") com o essencial visível; (b) "Brasil / Todos" mostra 3
   candidaturas do Missão (são 547): definir semântica de "Todos os cargos" (soma por cargo com detalhamento,
   ou exigir cargo com padrão sensato — deputado federal) e nunca mostrar número enganoso.
