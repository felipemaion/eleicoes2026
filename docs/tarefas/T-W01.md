# T-W01 — Scaffold do web: Vite + TypeScript, design tokens, layout e rotas
- **Papel:** frontend · **Fase:** F1 · **Branch:** `feat/frontend-scaffold`
- **Depende de:** —

## Objetivo
Esqueleto do dashboard com a estrutura das 5 telas, sistema visual e ferramental de teste.

## Contexto (leia antes)
`docs/arquitetura.md`, `docs/metodologia/cuidados.md` § Visualização, `.claude/agents/frontend.md`.

## Escopo (arquivos)
- `apps/web/` com pnpm, Vite, TypeScript estrito, ESLint, Vitest, Playwright, D3 v7, MapLibre GL,
  pmtiles; `src/{main.ts, rotas.ts, store.ts, tokens.css}`, `src/telas/*` (placeholders),
  `src/componentes/filtros/` (UF, cargo, grupo, ano), `src/dados/cliente.ts` (stub tipado).
- Telas (roteamento por hash): Visão geral · Mapa · Gastos · Evolução 2022×2026 · Candidato.
- Tokens de design (cores, tipografia, espaçamento) com tema claro/escuro e paletas de dados
  seguras para daltônicos (sequencial, divergente, categórica) como constantes únicas.
- Rodapé com fonte (TSE) e `dt_geracao`.

## Critérios de aceite (viram testes)
1. Store tipada: mudar filtro atualiza a URL (hash) e vice-versa (Vitest).
2. Navegação entre as 5 telas por teclado e mouse (Playwright smoke).
3. Paletas exportadas de um só módulo; teste garante nº de classes e contraste mínimo do texto.
4. `pnpm lint`, `pnpm typecheck`, `pnpm test` verdes; `pnpm build` gera bundle.
5. Layout responsivo até 360 px de largura sem rolagem horizontal.

## Fora de escopo
Mapa (T-W02) e gráficos (T-W03) — só os contêineres.
